# لَمّة — Lamma 🎮

موقع ألعاب جماعية مجاني بالكامل ويعمل كـ Static Website.

## الألعاب
1. أسرع واحد
2. حساب سريع
3. اختبر ذاكرتك
4. المخفي
5. ارسم وخمّن
6. إكس أو
7. مختلف
8. ما التالي؟
9. كلمة ناقصة
10. ردّة الفعل
11. تصنيف
12. أعلى أو أقل

## مبدأ المشروع
- لا قمار أو مراهنات.
- لا نرد أو ألعاب مبنية على الحظ كآلية أساسية.
- لا مشتريات داخلية.
- لا حسابات أو Backend في النسخة الحالية.
- لا خدمات خارجية مدفوعة.
- مصمم للعمل على الهاتف والكمبيوتر.

## التكلفة
النسخة الحالية لا تحتاج خادمًا أو قاعدة بيانات أو API مدفوعًا. GitHub Pages يستضيف الملفات الثابتة للموقع.

## تشغيل محلي
افتح index.html في المتصفح.

## تطوير مستقبلي بدون فرض تكلفة
يمكن إضافة ألعاب محلية أخرى، تحسين الرسوم، الأصوات المحلية، ووضع لاعبين على نفس الجهاز. اللعب الحقيقي بين أجهزة مختلفة يحتاج خدمة/خادم، لذلك لن يتم تفعيله تلقائيًا حتى لا تتحول اللعبة إلى خدمة مدفوعة.
