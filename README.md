# لَمّة — Lamma 🎮

منصة ألعاب جماعية قصيرة. النسخة الأولى Static وتعمل بدون Backend.

الألعاب الحالية:
- أسرع واحد
- ذاكرة
- المخفي
- ارسم وخمّن (واجهة أولية)
- تحدي الحساب
- إكس أو

قواعد التصميم:
- لا نرد.
- لا قمار أو مراهنات.
- لا ألعاب تعتمد على الحظ كآلية أساسية.
- لا محتوى غير مناسب.
- التركيز على المهارة والسرعة والتفكير والتخمين.

## التشغيل
المشروع Static ولا يحتاج Backend لتشغيل النسخة الحالية. على GitHub Pages سيكون index.html هو نقطة الدخول.

الخطوة التالية: غرف أونلاين حقيقية، لاعبين ونقاط، ثم إضافة ألعاب جديدة.
